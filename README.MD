# 🤖 Sunday — Simple AI Chatbot

A simple AI chatbot built using **Qwen3-8B**, an 8-billion-parameter language model. The LLM is accessed through **Hugging Face** and integrated using **LangChain**.

## ✨ Features

- 🤖 Qwen3-8B language model
- 🔗 LangChain integration
- 💬 Streamlit chat interface
- 🧠 Session-based chat history
- 📊 LangSmith tracking support
- ☁️ Hugging Face inference

## 🛠️ Tech Stack

- Python
- LangChain
- Qwen3-8B
- Hugging Face
- Streamlit
- LangSmith
